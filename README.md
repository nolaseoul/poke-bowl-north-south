# Poké Bowl

A north–south, fully simulated Pokémon football game for desktop and mobile browsers.

Both teams play automatically. Choose the broadcast speed, inspect all 22 position-specific scouting reports, and follow the live box score. Includes animated plays and two original Game Boy-style chiptune tracks.

Fan-made project. Pokémon names, characters, and sprites belong to their respective owners. Sprites are sourced from PokeAPI.
