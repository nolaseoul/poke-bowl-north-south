# Victory emotes

The 151 species retain their own named celebrations. Eight choreography families now use 16 half-beat keyframes, played at 130 BPM inside the 4.8-second score moment. They include heel-step struts, crossed shuffles, alternating knee hops, sharp robot locks, directional spins, arm-wave poses, backward heel slides and creature flops. Each routine opens with a brief windup and ends on a held native action pose with a holographic crown accent. Body scale and rotation stay bounded to preserve recognition. Limbs use existing credited directional action/run atlas frames rather than a static portrait wobble.

Reference study: [Fortnite’s official Get Griddy showcase](https://www.youtube.com/watch?v=Vezju7tEgAs), [Roblox Hype Dance preview](https://www.youtube.com/watch?v=laerRVqnhz8), and [Destiny 2 dance/emote reference reel](https://www.youtube.com/watch?v=x7zTo3vDJT0). The custom routines adapt stepping, accented poses and finishes to each Pokémon; no reference animation, soundtrack or video asset is bundled.

Field and Dance Cam use the same keyframe sample, facing, atlas frame and clock. Pause freezes both, all playback speeds retain the real-time celebration, and reduced effects uses one still victory pose. `tests/dances.cjs` verifies all 151 trajectories and synchronized render actors.
